# 小智设备桥接（astrbot_plugin_device_bridge）

把 **小智（xiaozhi.me / ESP32 系列语音助手）** 接到 **AstrBot**：
设备上说的话，交给你在 AstrBot 里配置的人格来回答，音色仍然由小智那边出。

> 本文里出现的「彭语涵」只是示例人格名。你的人设叫什么就用什么，
> 把示例里的名字替换掉即可，插件本身不绑定任何具体人设。

## 安装方式

- **插件市场**：AstrBot 面板 → 插件市场 → 搜索「小智设备桥接」→ 安装并启用
- **手动安装**：下载本仓库 Release 里的 zip，或直接把仓库内容放进 `AstrBot/data/plugins/astrbot_plugin_device_bridge/`，然后重载插件

---

## 二、工作原理

```
小智设备(ESP32)
      │ 语音
      ▼
小智云端 xiaozhi.me  ──MCP(WebSocket)──▶  本插件  ──HTTP──▶  AstrBot 人格/记忆/工具
      ▲                                        │
      └────────── 工具返回的文本 ◀─────────────┘
```

官方云端不能更换底层模型，所以本插件采用「工具转接」思路：
把你的问题交给插件，插件再向本机 AstrBot 取回答，返回给云端逐字念出。

---

## 三、能力与限制（先看清楚再装）

**能做的**

- 设备说话 → AstrBot 的人格回答（人设、记忆、知识库、工具全部复用）
- 只在被召唤时转接；也可设成常驻，全部由人格回答
- 把设备对话写回微信会话记录，并可选推送提醒
- 点歌（受音源限制）

**做不到的**

- **不能让设备播放音乐**：官方固件没有播放能力，只会把文字念出来。
  想让音箱真正出声，需要自建 `xiaozhi-esp32-server` 并由服务端推音频流，或刷带音乐能力的固件。
- 官方云端不提供自定义模型接口，所以人设/记忆仍在你的 AstrBot 里，云端只做转述
- 不能打断说话，延迟约 2~4 秒（每句话两次往返）

---

## 四、安装

1. 把 `astrbot_plugin_device_bridge` 目录放进 `AstrBot/data/plugins/`，
   或在面板「插件」页上传 zip，然后**启用**
2. 小智控制台 → 智能体 → **MCP 接入点** → 复制 Token
3. 打开插件的配置页（面板插件卡片上的入口，或 `http://<地址>:8765/config`）：
   - 填 **Token**
   - 选择 **发送人身份**（下拉，来自你已有的会话用户）
   - 保存，插件会自动重载

> API Key 不用手填，首次启动会自动生成并保存在插件目录 `runtime.json`（权限 600）。

## 五、配置说明

### 首屏只有两项必填

| 配置 | 说明 |
|---|---|
| 小智接入点 Token | 支持只贴 token，或贴整条 `wss://api.xiaozhi.me/mcp/?token=...`；留空表示不改动已保存的值 |
| 发送人身份 | 填的是「你是谁」，不是人格名字。微信、小智、企业微信都只是渠道，选同一个人即可 |

### 高级项（默认折叠，多数人不用动）

| 配置 | 默认 | 说明 |
|---|---|---|
| `push_to_wechat` | true | 设备聊完推一条到微信 |
| `require_trigger` | true | 只在被召唤时转接 |
| `trigger_words` | 示例词 | 召唤词，**必须改成你自己人格的名字** |
| `exit_words` | 退出/不聊了… | 结束对话的说法 |
| `user_alias` | 哥哥 | 人格称呼你的方式 |
| `quiet_hours` | 空 | 静音时段（如 `23:30-07:30`），此时段不推送 |
| `multi_device_enable` | false | 多设备独立记忆 |
| `push_bot_tag` / `push_user_tag` | 【小智】/【我】 | 推送里的双方标签 |
| `astrbot_session_id` | xiaozhi-wx | 设备会话标识，改了会另起一段记忆 |
| `trigger_idle_minutes` | 30 | 召唤后多久没说话自动退回小智 |

### 自动项（不需要你填）

面板地址、API Key、监听端口、平台 ID、日志级别都由插件自动决定或推断。

## 七、必须做的一步：改小智控制台的角色介绍

这一步插件代替不了（那是 xiaozhi.me 后台，没有开放接口）。
把下面这段贴进小智控制台的「角色介绍」，**把「某某」换成你自己人格的名字**，
并且和插件里的「召唤词」保持一致：

```
你是小智，默认自己回答用户。

只有用户话里出现「某某」时，才调用工具 ask_pengyuhan，
message 传用户原话（可去掉召唤词）；拿到结果后原样念出，不改写不总结。

用户说「不跟你说话了」「退出」「回小智」时，不要调用工具，自己回应即可。

其他任何情况都不要调用 ask_pengyuhan。
```

插件侧还有兜底：未命中召唤词时返回 `[SELF]`，模型会自己回答；
返回 `[SKIP]` 则完全沉默，不念任何内容。

## 八、身份统一说明

- 渠道（微信 / 小智 / 企业微信）只负责收发消息，不决定“你是谁”
- 插件只从一处取身份：`unified_user_id`，留空则依次回退 `mirror_user_id`、`astrbot_username`
- 启动时会做一次归一，把这三个字段同步成同一个值，避免按渠道分裂
- 人格、记忆、权限仍按各渠道原有逻辑，不做打通

## 九、本机接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 健康检查（含状态灯等级） |
| GET | `/diagnose` | 四项自检：Token / 连接 / 身份 / 推送 |
| POST | `/device/reconnect` | 手动重连云端 MCP（幂等） |
| GET | `/device/logs` | 最近 50 行日志 |
| GET | `/device/metrics` | 当日调用计数、运行时长 |
| GET/POST | `/device/config` | 读取/保存配置 |
| GET/POST | `/device/push` | 推送开关 |
| GET | `/config` | 独立配置页（不经面板也能开） |
| GET | `/v1/models` | OpenAI 兼容：模型列表 |
| POST | `/v1/chat/completions` | OpenAI 兼容：对话（支持流式） |

## 十、安全与隐私

- Token、API Key 只存本地文件，不上传第三方
- 日志中的账号会脱敏，推送失败不会重试刷屏（默认 0 次重试）
- 本机接口默认只监听 `127.0.0.1`；要供外部设备访问需自行改配置并做好网络隔离
- 插件不会修改你在小智云端的任何设置

## 十一、常见问题

**Q：设备说「我这边卡了一下，你再说一遍」**
A：多半是工具调用出错或超时。看插件目录 `xiaozhi.log`，或打开配置页点「一键自检」。

**Q：微信收不到回复**
A：检查是否开了「语音回复」——文字被转成音频时，某些渠道发不出去。插件会自动关掉设备会话的 TTS。

**Q：配置页一片空白 / 状态读取失败**
A：先看「一键自检」的结论；若提示页面桥不可用，升级 AstrBot 到支持插件页面的版本。

**Q：一定要装点歌插件吗**
A：不装也能用，只是点歌功能不可用。

**Q：会不会影响我正常微信聊天**
A：不会。设备对话走独立会话，只有开启推送时才会在微信里多一条消息。
